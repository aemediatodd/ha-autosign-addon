# AutoSign 使用说明

启动后点击“打开网页界面”，在 HA Ingress 页面中填写平台账户信息、启用平台并保存。配置即时生效，无需重启。

首次使用建议先点对应平台的“仅测试此平台”，确认后再启用每日定时。默认关闭所有平台和定时；小黑盒未测试，默认关闭。

- MIUI 历史版本：账号、密码。
- 好游快爆：抓包得到的完整表单请求体，不是 Cookie 头。
- 交易猫：Cookie（如需 CSRF，应包含 `_csrfToken`）。
- 天翼云盘：账号、密码；验证码或风控不能自动绕过。
- 网易云游戏：官网登录后开发者工具里的完整 Authorization 值。
- 小黑盒：Cookie、可选 IMEI。**未测试，旧接口不保证可用。**

推送支持 Qmsg、Server 酱、企业微信、钉钉。选择所需方式后展开同名配置区填写密钥。钉钉 `atuser`、`atMobiles` 可用英文逗号分隔多个值。

默认时区 Asia/Hong_Kong，计划每天触发一次；超过指定时间后启动会补执行。运行前持久化当日触发记录，崩溃中断后请人工确认再手动执行。手动按钮可重复提交，请查看平台结果。

凭据仅保存在加载项私有数据目录，HA 备份可能包含凭据。日志不输出上游原始响应或 HTTP 凭据。真实网站接口可能变化，详细测试范围见仓库 VALIDATION.md。
